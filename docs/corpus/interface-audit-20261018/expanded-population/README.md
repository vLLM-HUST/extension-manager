# Expanded MOD discovery and four additional public source audits

The old frozen24 are an experimental cohort, not the ecosystem universe. The
retained discovery snapshots contain90 organization repositories and101 unique
repository IDs after external indices and historical aliases. They identify49
non-template/non-host repositories declaring extension or control-provider
entrypoints: **33 public and16 access-restricted**. This is49 declared repository
boundaries, not49 independent algorithms or working/native-qualified MODs.

The intersection with old24 is21 (19 public+2 restricted);28 declared repositories
are outside it (14 public+14 restricted). Seven source-only/aggregate candidates
remain separate. A missing root project file is not proof that no nested MOD
exists. Fork identity, multiple entrypoints and components sharing one repository
are kept distinct from algorithm identity. This packet supplies only public
source. Restricted counts are explicitly not publicly reproducible here.

[inventory.json](inventory.json) defines every count and lists33 public rows.
[source-index.json](source-index.json) binds their exact project snapshots and
implementation sources by commit, Git blob and full-byte SHA256. The underlying
API captures were acquired18 October and reused19 October; analysis time is not
a new main observation. The original llm-optimizations ledger was not located;
its historical derivative was not treated as the original ledger.
